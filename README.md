# Weekend Unspoiled

A spoiler-free Monday roundup of the weekend's football across the top five leagues.

`index.html` is the digest: fixtures picked on pre-match prestige, never on how the
game went. `watch.html` is the player wrapper - it keeps the video fully covered
until the YouTube player API reports playback has started, so neither the thumbnail
(which usually has the scoreline painted into it) nor the video title is ever shown.

Generated by the tooling in `~/Developer/HighlightsDigest`.
